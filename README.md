> [!IMPORTANT]
> **Language-Only Reasoning:** AVF does **not** process any visual input directly. Instead, it reasons over structured text evidence logs pre-extracted by a large VLM (e.g., Qwen2.5-VL-72B). This decoupled design is our core contribution, allowing significant efficiency gains under strict hardware constraints.

This repository provides the **reproduction code, pre-trained weights, and our generated text evidence logs** for the Logic-V/AVF framework, which attains 59.4% accuracy on the EgoSchema causal video reasoning benchmark using only a **3B-parameter language reasoner**.

## 🏆 Key Results

Performance on the EgoSchema causal video reasoning benchmark (500-question subset):

| Reasoning Method | Accuracy | Parameters | Modality |
| :--- | :---: | :---: | :---: |
| **Single RL Expert (Ours)** | **59.0%** | 3B | Text Logs |
| **Full AVF Framework (CAHV)** | **59.4%** | 3B | Text Logs |

<details>
<summary><b>🔍 Transparency Note: Why we open-source raw predictions (Click to expand)</b></summary>
<br>
A core claim of our paper is that our Logic-V reward signal produces authentic but imperfect reasoning. To ensure full scientific transparency, we do <b>not</b> cherry-pick or post-process results.

Our model's outputs are occasionally messy and contain artifacts of the RL training process. This is <b>expected and by design</b>—the AVF routing architecture exists precisely to handle such cases. Inside the <code>evaluation/</code> directory, we explicitly provide our <b>unprocessed RL test result QA pairs (raw <code>.jsonl</code> prediction logs)</b> containing the complete <code>&lt;think&gt;</code> traces generated by our agent.

You can directly inspect the successful causal deductions, as well as its flawed artifacts (e.g., formatting drifts like <code>&lt;think&gt;\n &lt;think&gt;</code>), which explicitly validates the necessity of the AVF routing architecture.

> <b>Note on <code>[Generation Cleaned]</code> tags:</b> You may notice this tag at the end of some JSON responses. This is merely a programmatic artifact appended by our automated regex parser after successfully extracting the final multiple-choice answer. <b>The <code>&lt;think&gt;</code> reasoning traces themselves remain 100% raw and unaltered.</b>
</details>

## 🚀 1. Quick Start & Installation

Clone this repository and set up the environment. We recommend **Python 3.10+** and **CUDA 11.8+**.

```bash
git clone https://github.com/bitxige/Logic-V-Reasoner.git
cd Logic-V-Reasoner
```

Install the core dependencies (including `ms-swift`, `DeepSpeed`, and `qwen-vl-utils`):

```bash
pip install -r requirements.txt
```

## 📚 2. Data Sources (Important)

> [!IMPORTANT]
> This repository **does not redistribute** any third-party benchmark data. Users must download the raw datasets from the original sources, in accordance with each benchmark's license and terms of use.

### Required Benchmarks

| Benchmark | Used For | Official Source |
| :--- | :--- | :--- |
| EgoSchema | Causal video reasoning (main) | https://github.com/egoschema/EgoSchema |
| VSI-Bench | Embodied spatial reasoning | https://github.com/vision-x-nyu/thinking-in-space |
| UrbanVideo-Bench | Embodied spatial reasoning | https://github.com/EmbodiedCity/UrbanVideo-Bench |
| MVBench | Short-horizon recognition | https://github.com/OpenGVLab/Ask-Anything |
| Video-MME | Long-form video QA | https://github.com/BradyFU/Video-MME |
| MedQA-USMLE | Cross-domain medical pilot | https://github.com/jind11/MedQA |

### What We Do Provide

To facilitate reproduction without requiring users to re-run the expensive 72B vision encoder, we share **our own derived artifacts** generated from the above public benchmarks:

- **Text evidence logs** (`evaluation/*_72B-Int4_analysis.jsonl`): The structured propositional logs produced by our Task-Adaptive Perception Protocol (TAPP) applied to the public videos. These are our original processing outputs and contain no raw video data.
- **Raw prediction logs** (`evaluation/*_predictions.jsonl`): Our model's outputs, provided unaltered for transparency.

All original video data, question text, and ground-truth labels remain the property of the respective benchmark authors and must be obtained from the official sources above.

## 📥 3. Download Pre-trained Weights

To facilitate immediate reproduction, we open-source our 5600-step RL LoRA weights. You do not need to retrain the model from scratch.

Download the `adapter_model.safetensors` and place it in the `checkpoint/checkpoint-5600/` directory:

```bash
mkdir -p checkpoint/checkpoint-5600

# Download the core weights (228MB)
wget https://github.com/bitxige/Logic-V-Reasoner/releases/download/v1.0/adapter_model.safetensors \
  -O checkpoint/checkpoint-5600/adapter_model.safetensors
```

> [!WARNING]
> Ensure that the accompanying `adapter_config.json` is also placed in the same directory. Adjust paths if your local folder naming differs.

## 📊 4. Reproducing Evaluations (Inference)

All evaluation scripts are organized in the `inference/` directory.

> [!TIP]
> **Path Notice:** The exact filenames for your scripts or datasets might vary based on your local setup. Please verify and replace the placeholder paths in the commands below with your actual local file paths.

### A. Evaluate Single RL Expert (~59.0%)
Runs the single generalist expert trained via the Logic-V reward pipeline.

```bash
python inference/eval_rl_single_pass.py \
    --base_model_path "Qwen/Qwen2.5-3B-Instruct" \
    --model_path "checkpoint/checkpoint-5600" \
    --input_file "evaluation/egoschema_72B-Int4_analysis.jsonl" \
    --output_file "evaluation/RL-egoschema_predictions.jsonl"
```

### B. Evaluate SFT Baseline
For performance comparison against the standard supervised fine-tuned (SFT) model:

```bash
python inference/eval_sft_egoschema.py \
    --base_model_path "Qwen/Qwen2.5-3B-Instruct" \
    --lora_path "checkpoint/Qwen2.5-3B-Video-SFT/checkpoint-504" \
    --input_file "evaluation/egoschema_72B-Int4_analysis.jsonl" \
    --output_file "evaluation/sft_egoschema_predictions.jsonl" \
    --max_new_tokens 1024
```

### C. Evaluate Full AVF Framework (~59.4%)
To reproduce our peak performance, this script activates the **Consensus & Hostile Verification (CAHV)** routing protocol. It dynamically instantiates the *Generalist, Navigator, and Observer* experts using the shared 3B core, escalating high-entropy deadlocks to the 32B-INT4 Arbiter via API.

```bash
python inference/eval_avf.py \
    --base_model_path "Qwen/Qwen2.5-3B-Instruct" \
    --model_path "checkpoint/checkpoint-5600" \
    --input_file "evaluation/egoschema_72B-Int4_analysis.jsonl" \
    --output_file "evaluation/avf_egoschema_predictions.jsonl" \
    --n_votes 5 \
    --arbiter_api_url "http://localhost:8000/v1/chat/completions" \
    --arbiter_model_name "Qwen/Qwen2.5-32B-Instruct-AWQ"
```

## 🧠 5. Teacher Annotations

We provide the script used to generate the structured semantic logs from the 72B teacher model.

### Extract Visual Logs & Keyframes (72B-Int4)
This script uses Qwen2.5-VL-72B-Instruct-AWQ to build chronological semantic logs from public benchmark videos.

```bash
python scripts/analyze_egoschema_pipeline.py \
    --model_path "Qwen/Qwen2.5-VL-72B-Instruct-AWQ" \
    --video_dir "path/to/your/downloaded/videos" \
    --input_json "path/to/your/downloaded/egoschema.json" \
    --output_file "evaluation/egoschema_72B-Int4_analysis.jsonl" \
    --max_frames 24
```

> [!NOTE]
> Users must first download the raw video files from the official EgoSchema repository (see Section 2). This repository does not include any third-party benchmark data.

## 🛡️ Reproducibility Note

> [!NOTE]
> The reported accuracy (59.0% for the RL single-expert) was evaluated using `bfloat16` precision on a **single 48GB GPU** (e.g., vGPU-48GB / RTX 4090 / A800), which is efficient and sufficient for inference. *(During RL training, a dual-GPU setup was utilized solely for acceleration.)*
>
> Due to the inherent non-determinism in parallel CUDA operations, architectural variations in `bfloat16` matrix multiplications across different GPU models, and specific environment configurations, **you may observe natural minor fluctuations in the final reproduced accuracy.** To ensure transparency, our **exact raw prediction logs** containing the complete `<think>` traces are provided in the `evaluation/` directory.
